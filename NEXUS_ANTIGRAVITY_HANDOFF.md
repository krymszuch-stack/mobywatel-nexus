## Gate 1 — shared workflow engine (highest priority)
- Existing `src/lib/nexus/store.ts` persists drafts, replies, reminders, journey progress, PESEL flag and other local states in `nexus-pref`. `CASES` and `TIMELINE` in data.ts are static fixtures. Implement typed event log, derived case state, related entities and selectors. Keep one canonical state, not independent per-screen copies; use migration for persisted version 1 and preserve old drafts, settings and valid progress. Validate persisted values. Idempotent action IDs and timestamps. Do not introduce Kafka/DB/network for local demo.
- Fix `home.tsx`: `waiting[0] ?? LETTERS.find(letter => letter.needsReply)` resurfaces an already answered letter. Derive next action from unresolved tasks only, no stale fallback. All modes must display genuinely important actionable tasks without reshuffling familiar shortcuts.
- `sendReply` currently updates only replies/readIds. Add explicit letter-to-case mapping, case status transition (not automatic final decision), receipt and timeline event in one state transaction. When confirmed, all views must update immediately, survive reload and never imply a real submission. Clear or archive draft appropriately. Handle duplicate confirmation.
- `finishJourney` currently only sets done. Create/save a case and link related services, tasks, deadlines and timeline entries. Model dependencies and steps with actual completion checks; no false claim of official entitlement or completion.
- `Timeline` currently renders static events + reminders separately. Merge/sort canonical events; each item deep-links to related case/letter/service. Allow reminder edit/remove, actual selected date/time and sensible empty state. Internal navigation should preserve scroll, return state and support browser Back/deep link if feasible.
- PESEL, lost documents and sharing: simulate transitions with confirmation and clear consequences, update security and document views and timeline; expiry must refresh automatically while screen is open. Distinguish time-limited local preview from actual sharing. No real QR credentials.

## Gate 3 — visual and adaptive experience
- Use reference boards in `reference/` as inspiration, not pixel-perfect specs. Existing `UI_CONTRACT.md` contains stale restrictions (max radius 2px, no external links except tel) contradictory to CSS and official handoffs. Update contract narrowly to reflect latest user direction: recognizable contemporary mObywatel first, world-class service orchestration second, Polish heritage third. Keep typography IBM Plex (sans for functional text, serif only selected titles), local glyphs and watermarks, semantic colors, WZÓR / independent demo notice. Make palette single source of truth; remove conflicting CSS overrides, decorative colored circles, gradients, random shadows; use controlled radii e.g. 12–16px for main cards, smaller for controls. No official seal/emblem copied from boards.
- `public/glyphs/` contains 48 SVG files; verify parity with `glyph-paths.ts`, review recognizable shapes and optical balance. No Lucide imports in product UI; remove dependency only if unused. No default AI sparkle. Keep Orbit.
- Desktop side nav currently 15 entries, mobile five (Pulpit/Dokumenty/Szukaj/Usługi/Profil). Preserve mobile familiarity, group desktop into same top-level areas with expandable sections and easy access to Sprawy and e-Doręczenia. Do not change service labels unnecessarily.
- Onboarding already supports three modes. Add genuine previews, immediate text sizing and optional mode switching. Simple mode: 4 large stable actions (mDowód, mojeIKP, e-Doręczenia, preferred support), expandable full catalogue without duplicate shortcuts, persistent help, 56px targets, 18–20px default text, one action per step, optional read-aloud when supported. No mandatory age collection; allow user-selected pins. Standard: mDowód one tap, one priority card, search, favorites, grouped services. Dense: useful status, shortcuts, quick filters; no clutter.
- Preserve 3 themes, high contrast removes decoration, independent heritage toggle and reduced-motion. Optimize local SVG, avoid animations blocking actions. Historical motifs are original decorative assets at ~2–5% opacity; not authenticity signals. No misleading official identifiers.
- `matchOrbit` is keyword matching, not AI. Improve normalized intent aliases, full-sentence multi-intent routing, deduplicated results, empty results and contextual search. Optional AI only after deterministic demo passes; do not require API keys. Context assistance must be meaningful and provide human/official handoff.
- Accessibility: semantic labels, accessible dialogs, focus management, keyboard tabs (use valid tab roles or buttons), 200% text reflow, 320px width, contrast and no color-only status. Voice features must have fallback; no mic permissions unless user initiates. Test all modes.
