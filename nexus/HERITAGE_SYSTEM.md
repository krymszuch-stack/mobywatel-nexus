# Polish Heritage SVG

Oryginalne rysunki. Nie kopie banknotów, pieczęci ani rękopisów.

Komponent: `Watermark` w `src/components/nexus/heritage.tsx`.
Motywy: `rosette`, `fan`, `orbits`, `lattice`, `civic`, `manuscript`, `staff`, `lab`.

Krycie domyślne 0.05, na karcie dokumentu 0.07. Kolor `--nx-engraving` (granat albo szampan). W Kontrastu `.nx-mark` jest ukryty.

Przypisanie:

- Start — orbity albo krata.
- Dokumenty — rozeta, wachlarz, krata, laboratorium, zależnie od dokumentu.
- Pisma — rękopis, pięciolinia.
- Ścieżki lokalne — sylweta architektoniczna `civic` (własny rysunek dachów, nie konkretny zabytek).
- Wsparcie — krata.
- Oś czasu — orbity.
- Bezpieczeństwo — krata, bardzo cicho.
- 3 maja — rękopis do około 0.1, tylko ten motyw.

Nie dodawaj portretów. Nie wstawiaj cytatów z Konstytucji 3 Maja ani nut Chopina.
